  # 📝 Crear tu primer repositorio

  GitHub permite almacenar y compartir tus proyectos.

  ### Paso 1: Crear un repositorio
  1. Ve a [GitHub](https://github.com) y entra a tu cuenta.
  2. Haz clic en **New**.
  3. Nombre del repositorio: `mi-primer-repo`
  4. Marca **Add a README** (opcional)
  5. Haz clic en **Create repository**

  ### Paso 2: Clonar el repositorio
  ```bash
  git clone https://github.com/tu-usuario/mi-primer-repo.git
